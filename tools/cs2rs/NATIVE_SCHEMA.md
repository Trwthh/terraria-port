# Native tables: mapping library types and members to hand-written Rust

A native table tells cs2rs "this C# library type / member is implemented by this Rust". Everything the translated
code calls that no table maps becomes a generated host function that logs or panics; `HOST_API.md` lists those,
and for each one shows the exact key to write here and the Rust types the template receives and must produce.

Everything stated here is exercised by `tests\native.cs` (snippets `NativeBinaryReader`, `NativeBinaryWriter`,
`NativeTimeSpan`: the C# is run on .NET, translated, and the two outputs compared) unless a line says
"not tested".

## 1. Files and merging

| file | owner | content |
|---|---|---|
| `native.json` | cs2rs worker | collections, strings, `Math`, `UnifiedRandom`, ... |
| `native_xna.json` | generated by `gen_native_xna.py` | XNA value types from `terraria-core` |
| `native.d\rt_*.json` | cs2rs worker | types implemented in `terraria-gen-rt` (`rt_io.json`, `rt_time.json`) |
| `native.d\host_*.json` | host worker | types implemented in `terraria-host`, one file per area |

`native.json` has `"includeDirs": ["native.d"]`: every `native.d\*.json` is read in ordinal file-name order and
merged. The order has no effect on the result, because nothing may be defined twice:

- A key of `nativeTypes`, `nativeMembers`, `nativeSlices` or `stubs` that appears in two `native.d` files, or in a
  `native.d` file and in `native.json` / `native_xna.json`, stops the tool with
  `error: duplicate native member <key>: defined in <file A> and in <file B>` (exit code 1, nothing written).
- A `native.d` file may contain only those four objects. `types`, `namespaces`, `sources`, `include`... are an error.
- Comments (`//`) and trailing commas are allowed.

A config may switch entries of these tables off: `"ignoreNative": ["T:System.DateTime", "M:System.DateTime.*"]`
(exact keys, or a prefix ending in `*`). The member falls back to the host boundary; a member template whose
C# signature mentions an ignored TYPE is not used either. `game.json` lists the current ones with reasons.
`cs2rs --skip-native host_` leaves out every `native.d\host_*.json` (snippets and the core set).

After editing a table: `sh tools/cs2rs/run.sh` (90 s), then `cargo check -p terraria-gen-game`. A wrong Rust name or
type in a template is a rustc error in generated code; it is never silently wrong.

## 2. Schema

```jsonc
{
  "nativeTypes": {
    "<type id>": { "rust": "<Rust type>", "kind": "class" | "struct" | "value", "is": "<optional Rust expr>" }
  },
  "nativeMembers": {
    "<member id>": "<template>",                                   // method, constructor, operator, field
    "<property id>": { "get": "<template>", "set": "<template>" }  // either may be missing
  },
  "stubs": { "<member id>": "<Rust expression>" }                  // a fixed value; needs a reason in a comment
}
```

### Keys: Roslyn documentation ids

Copy them from the second column of `HOST_API.md`. The rules, for the cases that are easy to get wrong:

| C# | id |
|---|---|
| type | `T:System.IO.BinaryReader`, nested `T:Outer.Inner`, generic `` T:System.Collections.Generic.List`1 `` |
| method | `M:System.IO.Stream.Seek(System.Int64,System.IO.SeekOrigin)`; no parentheses when there are no parameters: `M:System.IO.Stream.Flush` |
| constructor | `M:System.IO.MemoryStream.#ctor(System.Byte[])` |
| property | `P:System.IO.Stream.Position`; indexer `P:System.String.Chars(System.Int32)` |
| field (also `static readonly`) | `F:System.TimeSpan.Zero` |
| operator / conversion | `M:System.TimeSpan.op_Addition(System.TimeSpan,System.TimeSpan)`, `op_Implicit(..)~ReturnType` |
| event accessor | `M:Some.Type.add_Changed(System.EventHandler)`, `remove_Changed` |
| `ref` / `out` parameter | `@` after the type: `M:System.Int32.TryParse(System.String,System.Int32@)` |
| array parameter | `System.Byte[]`, `System.Int32[0:,0:]` (two dimensions) |
| type parameter of the type / of the method | `` `0 `` / ``` ``0 ```: ``M:System.Array.IndexOf``1(``0[],``0)`` |
| generic argument | braces: `System.Collections.Generic.IEnumerable{System.String}` |

Every overload has its own id, so overloads need nothing special: one entry each. Several overloads may point at
the same generic Rust function (`BinaryWriter.Write(int)` -> `{this}.write::<i32>({0})`).

Inherited members: a call is looked up under the id of the member Roslyn binds, which is the override in the
static type of the receiver (`ms.Position` on a `MemoryStream` is `P:System.IO.MemoryStream.Position`). If that
id has no entry, the tool walks up the `override` chain and uses the entry of the member it overrides
(`P:System.IO.Stream.Position`). So map a virtual member once, on the class that declares it; add an entry for
an override only if it must behave differently.

### `nativeTypes`

| kind | the C# type is | Rust type of a value | `{this}` in a member template |
|---|---|---|---|
| `"class"` | a reference type | `Gc<rust>` | `(*receiver.ptr())`: a place of type `rust` (null receiver: `NullReferenceException`) |
| `"struct"` | a value type | `rust` | the place itself (a local, a field, an array element), so `&mut self` methods mutate in place |
| `"value"` | a reference type whose Rust type is already a `Copy` handle (`Seq<T>`) | `rust` | the value |

`rust` is a path as generated code sees it: `rt::...` (crate `terraria-gen-rt`), `terraria_core::...`,
`terraria_host::...`. A type parameter of a library member is a Rust type parameter of the host function whatever
its constraint (`where T : class` no longer erases to `Obj`). For a generic C# type, `{0}`, `{1}` are the Rust types of its type arguments
(``"T:System.Collections.Generic.Dictionary`2": { "rust": "Dictionary<{0}, {1}>", "kind": "class" }``).

`"is"` (kind `"class"` only): needed when several C# classes map to ONE Rust type. `x is C`, `x as C` and `(C)x`
first check that the object's Rust type is `rust`, then evaluate `is` with `{0}` = the `Gc<rust>` (never null).
Without `"is"` the Rust type alone decides.

### Templates

A template is a Rust expression. The tool substitutes text; write parentheses if precedence matters.

| placeholder | replaced by |
|---|---|
| `{this}` | the receiver, see the table above. Empty for static members |
| `{handle}` | the receiver of a class as its `Gc<T>` handle instead of the dereferenced place (when the Rust function wants the handle: `Dictionary::keys({handle})`) |
| `{0}`, `{1}`, ... | the arguments in parameter order, already converted to the parameter's type. Each appears once in the output if it appears once in the template; an argument the template does not mention is NOT evaluated, so mention every one (`{ let _ = {0}; ... }` to drop it) |
| `{args}` | all arguments, comma separated |
| `{value}` | the assigned value in a `set` template |
| `{T0}`, `{T1}` | Rust types of the method's type arguments (`rt::linq::empty::<{T0}>()`) |
| `{TT0}`, `{TT1}` | Rust types of the type arguments of the receiver's / constructed type (``List::<{TT0}>::new_gc()``) |
| `{ret}` | Rust type of the return value |
| `{raw0}` | argument 0 without the implicit reference conversion to the parameter type (`Array.Clear(Array, ..)` gets the typed `Arr<T>`); plain method calls only. An argument that is statically only a `System.Array` refuses the body |
| `{E0}` | `&` the generated `rt::EnumInfo` of the method's type argument 0, which must be an enum (`Enum.TryParse<TEnum>`) |

How each member kind is written:

- Instance method: `"{this}.read_i32()"`. Static method: `"rt::time::TimeSpan::from_seconds({0})"`.
- Constructor of a class: an expression of type `Gc<rust>`: `"rt::io::BinaryReader::new_gc({0})"`. Constructor
  of a struct: an expression of type `rust`. `new S()` without arguments on a native struct is always
  `rt::zero()` and needs no entry.
- Property, computed: `{ "get": "{this}.position()", "set": "{this}.set_position({value})" }`. Static
  property: the same without `{this}`. Indexer: `{0}` is the index.
- Property or field that IS a Rust field: a plain string, `"{this}.ticks"`. A string template on a property or
  field is a PLACE: translated code may assign to it, `+=` it and pass it by `ref`. Use the `get` / `set` form
  whenever the Rust side is a method call.
- Static field: `"rt::time::TimeSpan::ZERO"`.
- Operator: `"{0}.add({1})"`, `"({0} == {1})"`.
- Event of a library class: map the two accessors; `{0}` is the handler delegate (section 6). Not tested by a
  snippet: no native class with an event exists yet. Tell the cs2rs worker when you add the first one.
- A member that is left out stays in `HOST_API.md` and behaves as before (void: logs once and continues; value:
  panics). Leaving members out is fine; a wrong template is not.

## 3. What the runtime requires of a native CLASS

Crate layout: `terraria-host` depends on `terraria-gen-rt` (never on `terraria-gen`); `terraria-gen` depends on
`terraria-host` and names it in generated code through the templates. In `terraria-host` the runtime is
`terraria_gen_rt::rt` (everything is also re-exported at the crate root: `terraria_gen_rt::Gc`).

An object is a heap block: a 16-byte header (type id `u32`, liveness word, pointer to the Rust type's
`TypeInfo`), then the payload. `Gc<T>` is a raw pointer to the payload: `Copy`, null is the null pointer,
`==` compares addresses, `g.ptr()` checks for null (throws `NullReferenceException`) and returns `*mut T`,
`g.up::<U>()` retypes.

Requirements on `T`:

1. `T: rt::Trace + 'static`. `trace` must report every handle the object holds (`m.mark(self.stream)` for a
   `Gc`, `self.field.trace(m)` for `Str`, `Arr<T>`, `Delegate`, `Seq`, `Vec<T>`, `Option<T>`, nested structs).
   An object without handles sets `const NEEDS_TRACE: bool = false`. Missing a handle lets the collector free a
   live object: that is the one way a native type can corrupt memory.
2. Allocate with `rt::alloc_init(value)`: the header gets type id 0 ("not a translated class") and the
   `TypeInfo` of `T`. That `TypeInfo` carries the Rust `TypeId`, which is what `is` / `as` / casts from
   `object` check. Nothing else is needed for type tests.
3. `T` need not be `Copy` and need not be valid as zero bytes (unlike translated classes): it may own a `Vec`,
   a `File`, a GPU handle. `Drop` runs when the collector sweeps the object. Alignment at most 16.
4. No interior Rust references to other game objects; hold `Gc` / `Str` / `Arr` handles.
5. Methods take `&self` / `&mut self`. The `&mut` exists for the duration of one call. A native method must
   not call back into translated code while it holds a reference to its own object, unless it has copied what
   it needs out first (handles are `Copy`); invoking a delegate (section 6) is such a call.

Class hierarchies: `Gc<Derived>` is passed where C# expects the base class with NO conversion code, so base and
derived classes must map to the same Rust type, or to types where the base is the first field of a
`#[repr(C)]` derived struct. The simple and tested form is one Rust type for the hierarchy with an `"is"`
template per class (`Stream` / `MemoryStream` / `FileStream` -> `rt::io::Stream`).

Limits, all visible as rows in `HOST_API.md` rather than as wrong behaviour:

- A library class derived from a mapped one that is itself not mapped (`CryptoStream : Stream`) is an opaque
  object; calls on it stay host functions even when the base member is mapped.
- A call through a library interface or through `object` on a native object (`IDisposable.Dispose()` on a
  variable typed `IDisposable`, `object.ToString()`) is a host function `host::api::...`, not your method.
  `using (var r = new BinaryReader(..))` is fine: the static type is the class, so `Dispose` binds to it.
- `MemberwiseClone` of a native object that owns memory panics (also of a translated class with a native base).
- `object.ToString()` / `Equals` / `GetHashCode` on a native object reach `rt::Trace::obj_to_string / obj_equals /
  obj_hash` of its Rust type (default: the Rust type name / identity). Override them in the `Trace` impl when the
  game can observe the C# behaviour. A call through any OTHER library interface on a native object
  (`IDisposable.Dispose()` on a variable typed `IDisposable`) is still a host function `host::api::...`: for a
  `void` member that logs once and continues, i.e. the native `Dispose` does NOT run. Not fixed in this stage.

### 3a. A translated class deriving from a native class

`class ClusterGroup : List<Cluster>`, `Main : Game`. The translated struct embeds the native VALUE as its first
field:

```rust
#[repr(C)]
pub struct Bag {                       // class Bag : List<int> { public string label; }
    pub base: rt::NativeSlot<List<i32>>,
    pub label: Str,
}
```

- A `Gc<Bag>` is also a valid `Gc<List<i32>>` (pointer cast, the rule for translated bases): upcasts, `foreach`,
  passing it where `List<int>` / `IEnumerable<int>` is expected need no code beyond the retype. `x is Bag` and
  `(Bag)list` use the object's type id as for any class. Such a class is not `Copy`.
- `: base(args)` (or the implicit `: base()`) expands the native CONSTRUCTOR template, which returns a `Gc<Native>`,
  and moves the value into the slot (`rt::NativeSlot::init`); the temporary object is emptied. So a class that is
  derived from needs constructor templates for every base constructor the game calls; a missing one is a refused
  constructor ("constructor of the native base class has no template"). The slot is empty (not traced, not
  dropped) until then.
- Members of the native class called on the subclass (`Count`, `this[i]`, `Add`, `base.Count`) use the ordinary
  templates with `{this}` = the embedded value.
- Requirement on the native type: nothing new. It must not assume its address is the start of a heap object of
  its own Rust type (`rt::as_rt::<Gc<Native>>(obj)` is false for a subclass object: its Rust type is the subclass).

Snippet `NativeBaseList` (tests\native.cs: `Bag : List<int>`, `BigBag : Bag`).

Virtual members that translated code overrides and NATIVE code calls (`Game.Run` calling `Main.Update`,
`Stream.Read` called by a native reader): the runtime side exists, the generator side does NOT yet.

- `rt::NativeVirtuals` (implemented by the native class): `const VIRTUALS: &[&str]`, the documentation ids of the
  virtual members whose native entry point asks for an override first.
- Native entry point: `if let Some(f) = unsafe { rt::native_override::<unsafe fn(Obj, GameTime)>(self as *const Self as *const u8, "M:Microsoft.Xna.Framework.Game.Update(Microsoft.Xna.Framework.GameTime)") } { return unsafe { f(this_obj, time) } }`,
  else the native default. `base.Update(time)` from translated code should map to a separate non-dispatching
  function.
- Generated side (TO DO): each translated subclass registers a thunk per override with
  `rt::native_register_override::<Native, F>(TYPE_ID, slot, thunk)`; registering a slot the native class does not
  list panics, so an override the native code would never call cannot go unnoticed. Until the generator emits
  these registrations an override is only reached from translated code through the static type; a call that
  starts in native code runs the native default. `Main.Initialize / LoadContent / Update / Draw` are called
  directly by the host loop today, which is why Proof 1 does not depend on this.

### Worked example: `System.IO.BinaryReader` over a byte buffer

Rust (`port\crates\terraria-gen-rt\src\rt\io.rs`, abridged):

```rust
pub struct Stream { buf: Vec<u8>, pos: usize, readable: bool, /* ... */ }
unsafe impl Trace for Stream {                       // owns bytes, holds no handles
    const NEEDS_TRACE: bool = false;
    unsafe fn trace(&self, _m: &mut Marker) {}
}
impl Stream {
    pub fn from_bytes(bytes: Arr<u8>) -> Gc<Stream> { // new MemoryStream(byte[])
        if bytes.is_null() { throw(exc("System.ArgumentNullException", Str::lit("buffer"))) }
        alloc_init(Stream { buf: bytes.as_slice().to_vec(), pos: 0, readable: true, /* ... */ })
    }
    pub fn position(&self) -> i64 { self.pos as i64 }
    pub fn is_file(&self) -> bool { self.path.is_some() }
}

#[derive(Clone, Copy)]
pub struct BinaryReader { pub stream: Gc<Stream>, leave_open: bool }
unsafe impl Trace for BinaryReader {                 // one handle: reported
    unsafe fn trace(&self, m: &mut Marker) { m.mark(self.stream) }
}
impl BinaryReader {
    pub fn new_gc(stream: Gc<Stream>) -> Gc<BinaryReader> { alloc_init(BinaryReader { stream, leave_open: false }) }
    pub fn read_i32(&mut self) -> i32 { i32::from_le_bytes(self.fill()) }   // fill() throws EndOfStreamException
    pub fn read_string(&mut self) -> Str { /* 7-bit length, UTF-8 */ }
}
```

Table (`native.d\rt_io.json`, abridged):

```jsonc
"nativeTypes": {
  "T:System.IO.Stream":       { "rust": "rt::io::Stream", "kind": "class" },
  "T:System.IO.MemoryStream": { "rust": "rt::io::Stream", "kind": "class", "is": "!(*{0}.ptr()).is_file()" },
  "T:System.IO.BinaryReader": { "rust": "rt::io::BinaryReader", "kind": "class" }
},
"nativeMembers": {
  "M:System.IO.MemoryStream.#ctor(System.Byte[])": "rt::io::Stream::from_bytes({0})",
  "P:System.IO.Stream.Position": { "get": "{this}.position()", "set": "{this}.set_position({value})" },
  "M:System.IO.BinaryReader.#ctor(System.IO.Stream)": "rt::io::BinaryReader::new_gc({0})",
  "M:System.IO.BinaryReader.ReadInt32": "{this}.read_i32()",
  "M:System.IO.BinaryReader.ReadString": "{this}.read_string()",
  "M:System.IO.BinaryReader.Dispose": "{this}.close()"
}
```

C# and what it becomes:

```csharp
MemoryStream ms = new MemoryStream(data);            // let mut ms: Gc<rt::io::Stream> = rt::io::Stream::from_bytes(data);
BinaryReader r = new BinaryReader(ms);               // let mut r: Gc<rt::io::BinaryReader> = rt::io::BinaryReader::new_gc(ms);
int n = r.ReadInt32();                               // let mut n: i32 = (*r.ptr()).read_i32();
long p = r.BaseStream.Position;                      // (*(*r.ptr()).base_stream().ptr()).position()
if (o is MemoryStream) ...                           // !rt::as_rt_if::<Gc<rt::io::Stream>>(o, |__h| !(*__h.ptr()).is_file()).is_null()
BinaryReader again = (BinaryReader)o;                // rt::cast_rt::<Gc<rt::io::BinaryReader>>(o)   (InvalidCastException otherwise)
catch (EndOfStreamException) ...                     // rt::exc_is(e, "System.IO.EndOfStreamException")
```

Tests: `rt::io::tests` (Rust unit tests: the byte encoding, end of stream, closing, a file round trip) and the
snippets `NativeBinaryReader` / `NativeBinaryWriter`. Run: `cd port && cargo test -p terraria-gen-rt`.

## 4. What the runtime requires of a native STRUCT

1. `Copy + 'static`, and every bit pattern of all-zero bytes must be a valid value that means `default(T)`:
   locals, fields, array elements and `new T()` start as zero bytes. No `Vec`, no `Box`, no Rust enum without
   a zero variant, no `NonNull`. Handles (`Gc`, `Str`, `Arr`) are fine: zero is null.
2. `unsafe impl rt::Trace`: `NEEDS_TRACE = false` and an empty `trace` if it holds no handles, else report them.
3. Boxing (`(object)x`, `x is T` on an object, a `T` in an `object[]`, string concatenation through `object`):
   `const BOX: rt::BoxKind = rt::BoxKind::Value(ID)`. Ids: `terraria-host` numbers its structs
   `rt::tid::HOST_FIRST + n` (`0x4000_0000` up) in one module of its own; the generator never assigns that range.
   A struct without `BOX` compiles until some C# boxes it, then fails at compile time (`rt::box_id`).
4. If the game uses it as a dictionary / hash-set key or in `List.Contains` / `IndexOf` / `Remove`:
   `impl rt::CsKey` with the type's `Equals` and `GetHashCode` (the hash need not equal .NET's number unless
   enumeration order of a `Dictionary` keyed by it matters; `Dictionary` enumerates in insertion order here as
   in .NET, independent of the hash).
5. `where T : IComparable<T>` code and `List<T>.Sort()` need `Trace::cs_compare` / `rt::sys::CsOrd`.
6. Fields are read and written in place by generated code only through the templates you give (a string
   template `"{this}.x"` makes `v.X = 1`, `v.X += 2` and `ref v.X` work).

Methods that C# calls on a value (`a.Add(b)`) get `{this}` = the place: `&self`, `&mut self` and by-value
`self` (the type is `Copy`) all work.

### Worked example: `System.TimeSpan`

Rust (`port\crates\terraria-gen-rt\src\rt\time.rs`, abridged):

```rust
#[repr(C)]
#[derive(Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
pub struct TimeSpan { pub ticks: i64 }               // zero bytes = TimeSpan.Zero

unsafe impl Trace for TimeSpan {
    const NEEDS_TRACE: bool = false;
    const BOX: BoxKind = BoxKind::Value(tid::TIME_SPAN);
    unsafe fn trace(&self, _m: &mut Marker) {}
}
impl CsKey for TimeSpan {
    fn cs_eq(&self, o: &Self) -> bool { self.ticks == o.ticks }
    fn cs_hash<H: Hasher>(&self, h: &mut H) { h.write_i32((self.ticks as i32) ^ ((self.ticks >> 32) as i32)) }
}
impl TimeSpan {
    pub const ZERO: TimeSpan = TimeSpan { ticks: 0 };
    pub fn from_seconds(v: f64) -> TimeSpan { /* .NET Framework: rounds to whole milliseconds */ }
    pub fn total_seconds(&self) -> f64 { self.ticks as f64 * 1e-7 }
    pub fn add(self, o: TimeSpan) -> TimeSpan { /* OverflowException like .NET */ }
}
```

Table (`native.d\rt_time.json`, abridged):

```jsonc
"nativeTypes": { "T:System.TimeSpan": { "rust": "rt::time::TimeSpan", "kind": "struct" } },
"nativeMembers": {
  "M:System.TimeSpan.#ctor(System.Int64)": "rt::time::TimeSpan::new({0})",
  "F:System.TimeSpan.Zero": "rt::time::TimeSpan::ZERO",
  "M:System.TimeSpan.FromSeconds(System.Double)": "rt::time::TimeSpan::from_seconds({0})",
  "P:System.TimeSpan.Ticks": { "get": "{this}.ticks" },
  "P:System.TimeSpan.TotalSeconds": { "get": "{this}.total_seconds()" },
  "M:System.TimeSpan.op_Addition(System.TimeSpan,System.TimeSpan)": "{0}.add({1})",
  "M:System.TimeSpan.op_LessThan(System.TimeSpan,System.TimeSpan)": "({0} < {1})"

```

The snippet `NativeTimeSpan` covers: a field of a class and an array of the struct starting as `Zero`, copies,
`ref` / `out` to an array element and to a field, operators, boxing and `is` / unboxing, `TimeSpan?`,
`Dictionary<TimeSpan, string>` and `List<TimeSpan>.IndexOf` (through `CsKey`), an exception thrown by the

## 5. Values that cross the boundary

| C# | Rust | notes for native code |
|---|---|---|
| `bool`, `byte`..`ulong`, `float`, `double` | `bool`, `u8`..`u64`, `f32`, `f64` | |
| `char` | `u16` | one UTF-16 unit |
| an enum | its underlying integer (`i32` unless declared otherwise) | members arrive as numbers: `SeekOrigin.End` is `2` |
| `string` | `Str` | `Copy`; null is `Str::NULL` (`is_null()`), distinct from `""`. `s.as_str()` gives `&str` (throws `NullReferenceException` on null), `s.get()` gives `Option<&str>`. Make one with `Str::new(&str)` (allocates) or `Str::lit("literal")`. `==` on `Str` is not defined: `rt::str_eq(a, b)`. `Length` and indices are UTF-16 units (`s.len()`, `s.char_at(i)`) |
| `T[]`, `T[,]`, `T[,,]` | `Arr<T>`, `Arr2<T>`, `Arr3<T>` | handles, `Copy`, null possible. `a.len()`, `*a.at(i)` (bounds-checked, throws `IndexOutOfRangeException`), `a.as_slice()` (valid until the next collection; copy out before calling back into game code), `Arr::new(n)`, `Arr::from_slice(&[..])`. Element writes by native code are visible to the game: it is the same array |
| `object`, an interface, an unmapped class | `Obj` (= `Gc<Object>`) | opaque. `rt::as_rt::<Gc<T>>(o)` / `rt::cast_rt` recover a native class, `rt::obj_as_str(o)` a string, `rt::unbox::<T>(o, id)` a boxed value |
| a native class | `Gc<T>` | |
| a native struct | `T` | |
| `T?` | `Nullable<T>` | `has_value`, `value` |
| `List<T>`, `Dictionary<K,V>`, `HashSet<T>`, `Queue<T>`, `Stack<T>` | `Gc<List<T>>` ... | the runtime's own types (`rt::collections`) |
| `IEnumerable<T>` | `Seq<T>` | |
| a delegate type | `Delegate<dyn Fn(A, B) -> R>` | section 6 |
| `ref T` / `out T` parameter | `*mut T` | points at the caller's variable, field or array element, valid for the call. `out`: the callee must write it. Template: `"rt::sys::try_parse_i32({0}, {1})"`, `{1}` is already the pointer |
| a translated game class / struct | `Gc<terraria_gen::gen::...>` / the struct | only nameable from `terraria-gen` itself, so a `terraria-host` signature cannot mention it; take `Obj` or the plain fields instead |
| an unmapped library struct | an opaque 32-byte struct generated per type | map the type (`nativeTypes`) before implementing members that take it |

Generic members: `{T0}` / `{TT0}` are substituted with Rust types, so the Rust function is generic over
`T: rt::Val` (`Copy + 'static + Trace`).

## 6. Delegates and events

A C# delegate value is `Delegate<dyn Fn(A, B) -> R>` (`ref` / `out` parameters are `*mut T`): a `Copy` handle
to an invocation list, null possible (`d.is_null()`).

- Native code calls one: `d.invoke(|f| f(a, b))`. Every target runs in order; the last result is returned, as
  in .NET. A null delegate throws `NullReferenceException`.
- Native code creates one for the game: `Delegate::new(Box::new(move |a: i32| -> bool { .. }))`. If the
  closure captures handles, use `Delegate::new_traced(closure, tracer)` where the tracer marks them.
- A native object that stores a delegate (an event) keeps the `Delegate` in a field and reports it in `trace`.
  `add_X` is `self.x = Delegate::combine(self.x, handler)`, `remove_X` is `Delegate::remove(self.x, handler)`
  (they implement .NET's multicast rules).
- Raising an event from native code runs translated code: do it only at points where the game expects
  callbacks (inside a call the game made, or from the host loop between ticks), never during `rt::collect()`.

## 7. Exceptions thrown by native code

`rt::throw(rt::exc("System.IO.EndOfStreamException", Str::lit("message")))` unwinds as a C# exception: a
translated `catch (EndOfStreamException)`, `catch (IOException)` or `catch (Exception)` catches it. The base
types of the `System` exceptions are a table in `rt::exc` (`parent`); a kind not listed there derives from
`System.Exception` only. If the game catches a base type of an exception you throw and that pair is missing
from the table, tell the cs2rs worker (one line there).

A plain Rust `panic!` is NOT a C# exception: translated `catch { }` blocks let it through and the process
stops. That is the right response to "the host does not implement this", and the wrong one for a condition the
game handles (`FileNotFoundException`, `EndOfStreamException`, `FormatException`...): the game uses
`try { } catch { }` as control flow in several loaders.

Native code runs between `catch_unwind` frames of translated code, so it must be unwind-safe in the plain sense:
no lock or half-updated global left behind when it throws.

## 8. Memory and threads

- One thread runs all translated code and every native call (`rt::enter()` asserts it in debug builds). The
  game's worker threads (world generation, `Task.Run`, `ThreadPool`) are to be run synchronously on that thread
  by the host mappings. `Gc`, `Str`, `Arr`, `Delegate` are `!Send`.
- The collector runs only when the host calls `rt::collect()`, between ticks, with no translated code on the
  stack. Handles in Rust locals are therefore safe during any native call.
- A handle that native code keeps BETWEEN calls must be reachable from a traced object, or held in an
  `rt::Rooted<T>` (a root for as long as it lives; thread-local statics are fine), or be registered with
  `rt::add_root`. A handle parked in a plain `static` / `thread_local` without `Rooted` dangles after the next
  collection. `Str` and `&str` from `as_str()` follow the same rule.
- Debug aids: `rt::set_poison(true)` and the cargo feature `gc-check` (DESIGN.md section 9) turn a stale handle
  into a panic.

## 9. Check list for a new mapping

1. Find the rows in `HOST_API.md`; copy the keys.
2. Implement the Rust type and functions in `terraria-host` with unit tests against .NET Framework behaviour
   (a value run through the real game, or the reference source, not .NET 8 where they differ).
3. Add `native.d\host_<area>.json`; `sh tools/cs2rs/run.sh`; the members leave `HOST_API.md`.
4. `cargo check -p terraria-gen`. Errors point into generated code at the template's expansion.
5. For a construct this file marks "not tested", or anything section 3 lists as a limit, ask for a snippet.
